# hxwl-04 根测仪与工作长度台账

牙体牙髓科电子根测仪台账：按牙位锁定设备、工作长度复测复核、归还登记与历史追溯。

## 技术栈

React + Vite + TypeScript + CSS（无新增依赖）

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5104

## 功能

- **设备台账**：按「使用中 / 在库可用 / 待检区」分区；校准到期日、主机与探头状态一目了然，校准过期或维修中的设备只能留在待检区
- **治疗前锁定**：为牙位锁定一台设备，同一台设备同一时段不能被两个牙位占用，待检区设备禁止锁定
- **测长与复测**：换设备复测时保存上一长度、上一设备与原因；新旧读数相差超过 0.5mm 自动停在待复核，确认后才能进入预备
- **归还登记**：登记主机状态、探头状态与实际使用时长，异常部件自动转维修并留在待检区
- **历史追溯**：占用与测长流水持久化到 localStorage，重开页面仍可按牙位追到每次记录

## 目录结构（资料 / 判断 / 保存 / 页面分离）

```
src/
  data/seed.ts          资料：设备与牙位种子数据
  domain/types.ts       资料：领域类型
  domain/rules.ts       判断：待检区、占用冲突、0.5mm 复核线、进入预备条件
  store/storage.ts      保存：localStorage 读写
  store/useLedger.ts    保存：台账操作（锁定/测长/复核/归还/维修/校准）
  components/           页面：设备台账、牙位台账、历史流水、三类表单
  App.tsx               页面：组装看板
```
