# hxwl-04 牙科根管治疗 · 根测仪与工作长度台账

按牙位组织根管步骤、工作长度与复诊计划。看板已扩展为电子根测仪台账：治疗前锁定设备、测长复核、归还登记与按牙位追踪。

## 技术栈

React + Vite + TypeScript + CSS（无新增依赖）

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5104

## 功能

- **设备看板**：每台根测仪的校准到期日、探头状态与所在区域（可用 / 使用中 / 待检区）；校准过期或探头维修中的设备只能留在待检区，支持登记校准与维修完成转回。
- **治疗前锁定**：为牙位锁定一台设备；同一台设备同一时段不能被两个牙位占用，一个牙位同时只能持有一台设备。
- **测长与复核**：换设备复测必须填写原因，并自动保存上一长度与上一设备；新读数与旧值相差超过 0.5mm 时停在「待复核」，确认后牙位才能进入预备。
- **归还登记**：记录主机状态、探头状态与实际使用时长；任一项异常设备自动转入维修（待检区）。
- **按牙位追踪**：每个牙位的每次占用与测长记录时间线；数据存于 localStorage，重开页面不丢失。

## 目录结构（资料 / 判断 / 保存 / 页面分离）

```
src/
├── data/seed.ts            # 资料：设备档案、牙位表、初始台账
├── domain/
│   ├── types.ts            # 判断：设备 / 占用 / 测长模型
│   └── rules.ts            # 判断：区域推导、锁定校验、超差复核、归还转维修
├── storage/ledgerStore.ts  # 保存：localStorage 读写与重置
├── hooks/useLedger.ts      # 保存：台账状态自动落盘
├── components/             # 页面：看板、锁定、测长、归还、复核、追踪
└── App.tsx                 # 页面：组装与事件接线
```
